# #sekta таймер — пробная браузерная версия

[открыть таймер](https://dosvidannie.github.io/sekta-timer-preview/) · [инструкция](https://dosvidannie.github.io/sekta-timer-preview/instruction.html)

открывайте ссылку в safari. html-просмотрщик и вход в github не нужны. репозиторий содержит готовые публичные файлы приложения; созданные вами таймеры сохраняются на вашем устройстве в данных браузера. они не загружаются на github и не синхронизируются между устройствами.

используйте обычную вкладку, не приватную. очистка данных сайта может удалить локальные таймеры. для резервной копии и переноса используйте «поделиться» (json) и «импортировать». после статуса «готово к работе без интернета» доступна работа офлайн.

это пробная публикация для проверки в браузере, с тем же звуковым движком веб-версии. стабильность звука на конкретном ipad проверяется на устройстве.

сборка из локального проекта «приложение таймер», исходная ревизия 0fc2a5d36323272dd5916df530253275c2ebae37. личные данные, тренировочные json-файлы, исходное видео и рабочие материалы в публикацию не включены.
