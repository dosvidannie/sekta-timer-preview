# #sekta таймер — пробная браузерная версия

[открыть таймер](https://dosvidannie.github.io/sekta-timer-preview/) · [для продюсера](https://dosvidannie.github.io/sekta-timer-preview/instruction.html) · [для тренера](https://dosvidannie.github.io/sekta-timer-preview/trainer-instruction.html)

открывайте ссылку в веб-браузере. html-просмотрщик и вход в github не нужны. репозиторий содержит готовые публичные файлы приложения; созданные вами таймеры сохраняются на вашем устройстве в данных браузера. они не загружаются на github и не синхронизируются между устройствами.

используйте обычную вкладку, не приватную. очистка данных сайта может удалить локальные таймеры. для резервной копии и переноса используйте «поделиться» (json) и «импортировать». после статуса «готово к работе без интернета» доступна работа офлайн.

это пробная публикация для проверки в браузере, с тем же звуковым движком веб-версии. стабильность звука на конкретном устройстве проверяется на устройстве.

сборка из локального проекта «приложение таймер», исходная ревизия 18f6c23bde4bccc82ab22ba1c7ed6875366f7578. личные данные, тренировочные json-файлы, исходное видео и рабочие материалы в публикацию не включены.
