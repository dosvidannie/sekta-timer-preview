# #sekta таймер — пробная браузерная версия

[таймер](https://dosvidannie.github.io/sekta-timer-preview/) · [инструкция для продюсера](https://dosvidannie.github.io/sekta-timer-preview/instruction.html) · [материалы для тренеров на бали](https://dosvidannie.github.io/sekta-timer-preview/trainers-bali.html) · [материалы для тренеров в россии](https://dosvidannie.github.io/sekta-timer-preview/trainers-russia.html)

открывайте ссылку в веб-браузере. html-просмотрщик и вход в github не нужны. репозиторий содержит готовые публичные файлы приложения; созданные вами таймеры сохраняются на вашем устройстве в данных браузера. они не загружаются на github и не синхронизируются между устройствами.

используйте обычную вкладку, не приватную. очистка данных сайта может удалить локальные таймеры. для резервной копии и переноса используйте «поделиться» (json) и «импортировать». после статуса «готово к работе без интернета» доступна работа офлайн.

это пробная публикация для проверки в браузере, с тем же звуковым движком веб-версии. стабильность звука на конкретном устройстве проверяется на устройстве.

сборка из локального проекта «приложение таймер», исходная ревизия 8c2bf5afcd6a3f1b63469a6fd9cd73120705679a. личные данные, тренировочные json-файлы, исходное видео и рабочие материалы в публикацию не включены.

материалы для тренеров содержат полную инструкцию по таймеру во вкладке «таймер» и чек-листы подготовки. каждая версия — самостоятельный html-файл со встроенными изображениями; галочки сохраняются отдельно для бали и россии.
